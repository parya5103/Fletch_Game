How messaging works

This website has no mail server or message backend, so this page does something honest instead: the form below opens a pre-filled issue on the Arrow Out! GitHub repository. That issue tracker is where messages are actually read and answered.

  • You need a free GitHub account to submit the issue (sign up at github.com/signup).
  • GitHub issues are public. Never include passwords, payment details or other sensitive personal information.
  • Nothing leaves your device until you press Submit new issue on GitHub — the form only prepares the message in your browser.
  • Name and email are optional. If you add an email, replies arrive as comments on your issue.
