# Arrow Out! 🏹

A mobile-first **tap-away arrow puzzle** game — a single HTML file, zero dependencies, installable as a PWA.

Play online: `https://<your-user>.github.io/<repo>/` after enabling GitHub Pages (see below).

## How to play

- The board is a grid of arrows, each pointing up / right / down / left.
- Tap an arrow to launch it in the direction it points.
- An arrow can launch **only if nothing sits between it and the board edge** in its direction — if the ray is blocked, the tap is a mistake (1 of 3 hearts lost).
- Clear every arrow to win the level.
- **Undo** reverses your last launch, **Hint** highlights a guaranteed-safe arrow, **Restart** resets the level.

## Every level is solvable — guaranteed

Levels are generated by **reverse placement**: arrows are placed one by one, and an arrow is only put on a square where its exit ray to the edge is clear at that moment. Reversing that build order always yields a valid clear order, so:

- every level can be finished with zero mistakes,
- the Hint button can always point to a safe arrow,
- deadlock states are impossible.

## Features

- 📱 Mobile-first: touch pointer events, 44px+ tap targets, safe-area aware, portrait + landscape, works from 320px-wide screens.
- ⭐ 3-star scoring: ★★★ = no mistakes & no hints · ★★ = ≤2 mistakes & ≤1 hint · ★ = otherwise.
- 🗺️ Level map with best stars, locked padlocks and current-level highlight; endless procedurally generated levels.
- 🔊 Synthesized sound effects via the Web Audio API — no audio files, unlocked after the first interaction; mute toggle.
- 💾 Progress, best stars and stats auto-saved to `localStorage` and restored on reopen.
- 📲 PWA: runtime-generated manifest + canvas-generated icons, service worker for offline play, Android install prompt and iOS "Add to Home Screen" hint. Install success is reported honestly — never faked.
- 🏗️ Ad-ready architecture: banner/interstitial hook points are no-ops until an ad provider is wired in.
- 🎨 Dark neon theme, color-coded arrows, smooth overlay animations.

## Run locally

Just open `index.html` in a browser, or serve the folder over HTTP so the service worker can register:

```bash
npx serve .
# or
python3 -m http.server 8000
```

## Deploy on GitHub Pages

1. Push `index.html` and `sw.js` to your repository.
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/(root)` → Save.
3. Open `https://<your-user>.github.io/<repo>/` — install it from the in-game Install button (Android/Chrome) or Share → Add to Home Screen (iOS Safari).
