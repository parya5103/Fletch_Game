# Arrow Out! 🏹

A mobile-first **tap-away arrow puzzle** game — a single HTML file, zero dependencies, installable as a PWA. **100 levels** with built-in **Supabase cloud sync**.

Play online: `https://<your-user>.github.io/<repo>/` after enabling GitHub Pages (see below).

## How to play

- The board is a grid of arrows, each pointing up / right / down / left.
- Tap an arrow to launch it in the direction it points.
- An arrow can launch **only if nothing sits between it and the board edge** in its direction — if the ray is blocked, the tap is a mistake (1 of 3 hearts lost).
- Clear every arrow to win the level. Clear all **100 levels** to complete the campaign 🏆
- **Undo** reverses your last launch, **Hint** highlights a guaranteed-safe arrow, **Restart** resets the level.

## Every level is solvable — guaranteed

Levels are generated by **reverse placement**: arrows are placed one by one, and an arrow is only put on a square where its exit ray to the edge is clear at that moment. Reversing that build order always yields a valid clear order, so:

- every level can be finished with zero mistakes,
- the Hint button can always point to a safe arrow,
- deadlock states are impossible.

All 100 levels are verified solvable by this construction (levels ramp from 5 arrows on a 5×5 board up to ~60 arrows on a 9×9 board).

## Features

- 💯 **100 levels** with a smooth difficulty ramp (5×5 → 9×9, 5 → ~60 arrows) and a campaign-complete celebration
- ☁ **Cloud sync** — connect your own free [Supabase](https://supabase.com) project to sync best stars across devices (setup below)
- 📱 Mobile-first: touch pointer events, 44px+ tap targets, safe-area aware, portrait + landscape, works from 320px-wide screens
- ⭐ 3-star scoring: ★★★ = no mistakes & no hints · ★★ = ≤2 mistakes & ≤1 hint · ★ = otherwise
- 🗺️ Level map with best stars, locked padlocks and current-level highlight
- 🔊 Synthesized sound effects via the Web Audio API — no audio files; mute toggle
- 💾 Progress, best stars and stats auto-saved to `localStorage` and restored on reopen
- 📲 PWA: runtime-generated manifest + canvas-generated icons, service worker for offline play, Android install prompt and iOS "Add to Home Screen" hint — install success is reported honestly, never faked
- 🏗️ Ad-ready architecture: banner/interstitial hook points are no-ops until an ad provider is wired in
- 🎨 Dark neon theme, color-coded arrows, smooth overlay animations

## Cloud sync setup (Supabase, ~5 minutes)

The game talks to Supabase over plain REST — no SDK, no build step.

1. Create a free project at [supabase.com](https://supabase.com).
2. Open **SQL Editor** and run:

```sql
create table if not exists public.level_progress (
  player_id text not null,
  level int not null check (level between 1 and 100),
  stars int not null default 0 check (stars between 0 and 3),
  plays int not null default 0,
  updated_at timestamptz not null default now(),
  primary key (player_id, level)
);

alter table public.level_progress enable row level security;
create policy "anon read"  on public.level_progress for select to anon using (true);
create policy "anon write" on public.level_progress for insert to anon with check (true);
create policy "anon update" on public.level_progress for update to anon using (true) with check (true);
```

3. Go to **Project Settings → API** and copy the **Project URL** and the **anon public** key.
4. In the game: **Menu → ☁ Cloud sync** → paste the URL + key → **Connect & sync**.
5. On another device: same URL + key, plus paste your **Player ID** (shown in the dialog) to restore that device's progress.

> **Security note:** this setup lets anyone with your URL + anon key read/write any row — the unguessable Player ID acts as the secret. That's fine for casual game progress. For real accounts, upgrade the policies to Supabase Auth (email login) later — the client already isolates rows by `player_id`.

Progress syncs automatically after every level win; **Sync now** does a full two-way merge (best stars win, plays take the max). Offline? Everything still works and saves locally.

## Run locally

Just open `index.html` in a browser, or serve the folder over HTTP so the service worker can register:

```bash
npx serve .
# or
python3 -m http.server 8000
```

## Deploy on GitHub Pages

1. Push `index.html` and `sw.js` to your repository.
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/(root)` → Save.
3. Open `https://<your-user>.github.io/<repo>/` — install it from the in-game Install button (Android/Chrome) or Share → Add to Home Screen (iOS Safari).
