Arrow Out! — Privacy Policy

Last updated: 18 October 2026 · Game progress stays on your device. Reminders are local; system notifications are optional.

What the game stores

Arrow Out! has no accounts or sign-in. There is no server database for game progress. All your progress — current level, stars, coins, owned arrow styles and board themes, streaks, achievements and settings — is saved in your browser's localStorage, on your own device. The game does not upload this save. Reminder preferences and whether permission has already been requested are included in it. Separate local reminder metadata records interaction time and deduplication/test timestamps; it is not uploaded. Using Share sends the level, score or link you choose to share through your browser or clipboard.

  • Normal gameplay needs no external API. Loading or updating the public site contacts GitHub Pages (preview builds may use a different host); local reminders make no subscription or roster requests. Retiring an old push subscription can contact the browser's push service.
  • The game itself sets no cookies and runs no analytics or trackers. Progress lives in localStorage, and the service worker keeps cached copies of the game files for offline play — both stay on your device (see Advertising below for what could change if ads are ever enabled).
  • Installing the game (PWA) copies it to your device for offline play; it does not add any new data collection.
  • The Contact page sends nothing to this site: with JavaScript enabled it prepares a draft locally. Opening its link sends the subject and message to GitHub in URL query parameters, before an issue is submitted. Without JavaScript, submitting the form sends those parameters directly to GitHub. The URL may remain in browser history and GitHub logs; posting makes the issue and your GitHub username public. This is not a private contact channel. See GitHub’s privacy statement.

Local reminders and optional system notifications

Reminders are off for new players. An existing reminder preference is preserved as an in-game reminder choice. Settings → Notification & reminder settings offers 1, 1½ or 2 hours of inactivity. Checks run in the game page, with an in-game fallback. A closed, suspended or battery-restricted page cannot schedule them.

  • System notifications are separately optional. Permission is requested only by the explicit Allow button, once. If dismissed or denied, use browser site settings to change it; in-game reminders still work.
  • Where supported, a running background page can ask the site's service worker to display a local notification. Browser/OS settings may suppress it. No remote push, daily sender, external subscription roster or closed-browser delivery is used by this version.
  • Disabling reminders stops new requests and attempts to close local notifications. You can also revoke permission in browser settings.

Earlier versions stored device-linked push endpoints and encryption keys in Supabase and used GitHub Actions to send reminders. This version removes that sender and integration and attempts to unsubscribe an existing browser subscription, without requesting permission. Failed cleanup is reported with a retry option. Unsubscribing or clearing local data cannot erase old Supabase records, backups or logs. The site operator must delete the old roster separately; provider retention is managed by those providers. Do not post subscription identifiers in public issues. See Supabase's privacy policy and GitHub's privacy statement for those historical services.

Deleting your data

  • In the game: Settings → Reset all progress resets game progress and preferences. It also resets local reminder timing and disables reminders, and attempts to close local notifications. It does not clear the offline cache, revoke browser permission or erase historical provider records.
  • In your browser: clearing site data removes local game data. Use browser notification settings to revoke permission. Clearing local data cannot itself erase historical provider records.

Advertising

Arrow Out! currently loads no advertising SDK, AdSense code, ad cookies or consent-management system. The rewarded-hint screen is a labelled five-second demo, not a real ad. No advertising provider is integrated. If a future release adds ads, its actual provider, data use and required user choices must be reviewed, implemented and disclosed before enabling that release. No consent or legal-compliance guarantee is made for a future integration.

Security

Your game progress stays on your device, which limits exposure, and the public GitHub Pages site uses HTTPS. Still, no online service can guarantee absolute security: information that travels over the internet (requests to the hosting service or historical notification providers) can in principle be intercepted or accessed by the parties operating those services. Please keep sensitive personal details out of public GitHub issues.

Privacy requests and limitations

This page describes the implemented behaviour; it is not a legal compliance certification. There is no automated access-request service or private contact form. For a general privacy question, use the Contact page without including personal data. Do not put push endpoints, encryption keys or other identifiers in public issues. This page does not provide a private route for sensitive requests or guarantee provider-side deletion.

Children

Arrow Out! has no accounts, and the game itself never asks for a name or email address; the Contact page asks only for a subject and message. Do not put personal details in them. Current reminders store only local preferences/timing. Historical push identifiers and provider records are described above. Any future advertising integration needs a separate review of age, consent and applicable privacy requirements before launch.

Changes

If this policy ever changes (for example, if advertising or a backup service is added), the updated policy will be published on this page with a new last-updated date.

Contact

General questions: use the Contact page or open an issue directly at github.com/parya5103/Fletch_Game/issues. Both routes lead to public issues; do not include private data.
