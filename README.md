# Arrow Out! 🏹

![CI](https://github.com/parya5103/Fletch_Game/actions/workflows/ci.yml/badge.svg)

A mobile-first **tap-away arrow puzzle** game — an **installable PWA**, zero dependencies, fully offline-capable. **1000 levels**: a 50-level warm-up, then **EXTREME mode** — every level from 51 onward is a full 12×12 board packed with **100–130 arrows**. **3 free hints per level**, daily challenges, achievements, streaks, stars and synthesized background music.

## How to play

- The board is a grid of arrows, each pointing up / right / down / left.
- Tap an arrow to launch it in the direction it points.
- An arrow can launch **only if nothing sits between it and the board edge** in its direction — if the ray is blocked, the tap is a mistake (1 of 3 hearts lost).
- Clear every arrow to win the level. Clear all **1000 levels** to complete the campaign 🏆
- **Undo** reverses your last launch, **Restart** resets the level.
- **Hints:** 3 free per level (a badge on the Hint button counts them down). After that, watch a short demo ad to reveal another hint.

## Difficulty ramp

| Levels | Board | Arrows |
|---|---|---|
| 1–50 | 5×5 → 7×7 warm-up | 5 → 30 |
| 51–200 | 7×7 → 9×9 medium | up to 50 |
| 201–500 | 9×9 → 11×11 hard | up to 80 |
| 501–800 | 11×11 → 12×12 expert | up to 100 |
| 801–1000 | **12×12 (EXTREME)** | **100 → 130** |

From level 801 the gloves come off: every board is a full 12×12 grid with at least 100 arrows on it, climbing to 130 by level 1000. These boards are genuinely hard — plan multiple launches ahead.

## Every level is solvable — guaranteed

Levels are generated by **reverse placement**: arrows are placed one by one, and an arrow is only put on a square where its exit ray to the edge is clear at that moment. Reversing that build order always yields a valid clear order, so every level can be finished with zero mistakes, the Hint button can always point to a safe arrow, and deadlock states are impossible. For the extreme 100+ arrow boards the generator uses a **most-constrained-first** placement (the empty square with the fewest clear directions is filled first), which is what allows such dense boards to stay solvable. All 1000 levels are verified solvable with correct hints — and the CI workflow re-verifies this on every push.

## Features

- 💯 **1000 levels** — 50 warm-ups, then dense 100–130-arrow 12×12 EXTREME boards
- 💡 **3 free hints per level**, then a rewarded-ad hint (a clearly-labelled 5-second demo ad runs until a real ad provider is wired into `Ads.provider` — the rewarded flow is ready for AdSense/AdMob H5)
- 🌝 **Daily challenge** — a deterministic puzzle for every date, with streak tracking
- 🎖 **Achievements** — progress-based unlocks, viewable from the home screen
- 📊 **Statistics** — plays, stars, streaks and per-level bests
- 💾 **Auto-save** — stars, plays and current level save privately on your device; fully offline
- 📱 Mobile-first: touch pointer events, 44px+ action targets, safe-area aware, works from 320px-wide screens
- ⭐ 3-star scoring: ★★★ = no mistakes & no hints · ★★ = ≤2 mistakes & ≤1 hint · ★ = otherwise
- 🗺️ Level map with best stars, locked padlocks and current-level highlight
- 🔊 Synthesized sound effects **and ambient background music** via the Web Audio API — no audio files; separate sound & music toggles
- 📤 **Share buttons** — native share sheet with clipboard fallback (win dialog + main menu)
- 📲 **PWA**: real `manifest.webmanifest` + PNG icons, service worker (offline-first caching), Android install prompt, iOS Add-to-Home-Screen hint
- 🎨 Dark neon theme with light-mode toggle, color-coded arrows, smooth overlay animations, confetti wins

## Run locally

Just open `index.html` in a browser, or serve the folder over HTTP so the service worker can register:

```bash
npx http-server .
# or
python3 -m http.server 8000
```

Run the CI smoke tests locally:

```bash
node scripts/ci-test.js
```

## Deploy on GitHub Pages

1. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/(root)` → Save.
2. Open `https://<your-user>.github.io/<repo>/` — install it from the in-game Install button (Android/Chrome) or Share → Add to Home Screen (iOS Safari).
