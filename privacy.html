Arrow Out! — Privacy Policy

Last updated: 18 October 2026 · Game progress stays on your device. Optional reminders use external push services.

What the game stores

Arrow Out! has no accounts or sign-in. There is no server database for game progress. All your progress — current level, stars, coins, owned arrow styles and board themes, streaks, achievements and settings — is saved in your browser's localStorage, on your own device. The game does not upload this save. Using Share sends the level, score or link you choose to share through your browser or clipboard.

  • Normal gameplay needs no external API. Loading or updating the public site contacts GitHub Pages (preview builds may use a different host); enabling or disabling reminders contacts Supabase and your browser's push service.
  • The game itself sets no cookies and runs no analytics or trackers. Progress lives in localStorage, and the service worker keeps cached copies of the game files for offline play — both stay on your device (see Advertising below for what could change if ads are ever enabled).
  • Installing the game (PWA) copies it to your device for offline play; it does not add any new data collection.
  • The Contact page sends nothing to this site: with JavaScript enabled it prepares a draft locally. Opening its link sends the subject and message to GitHub in URL query parameters, before an issue is submitted. Without JavaScript, submitting the form sends those parameters directly to GitHub. The URL may remain in browser history and GitHub logs; posting makes the issue and your GitHub username public. This is not a private contact channel. See GitHub’s privacy statement.

Daily reminders (optional notifications)

New saves default to reminders off; existing preferences are preserved. Permission is requested only when you enable reminders in Settings. Your browser creates a Web Push subscription containing an endpoint and encryption keys. These are device-linked identifiers, stored in a Supabase database to deliver game reminders. No name, email or game progress is included. The sender runs in GitHub Actions five times a day on a fixed schedule (10:00, 12:30, 17:00, 19:30 and 23:00 India time), regardless of your time zone; delivery may be delayed.

  • Turning reminders off attempts to delete the send-list record and unsubscribe this browser. A connection or permission failure can prevent removal; the game reports failures. Expired endpoints are removed when the sender receives an expiration response. Deletion from the send list does not promise immediate erasure from provider backups or logs.
  • No application-level subscription expiry or fixed retention period is implemented. Records can remain until opt-out deletion succeeds or the sender removes an endpoint after a 404/410 response. Provider backup and log retention is managed by those providers.
  • You can revoke notification permission for the site any time in your browser settings. This stops permission to notify; it does not directly delete the Supabase record.

GitHub hosts the site and runs the sender; Supabase stores the subscription; your browser vendor's push service delivers messages. These services receive network metadata such as IP addresses and apply their own retention policies. See GitHub's privacy statement, Supabase's privacy policy, and your browser vendor's privacy policy. Subscription values should never be posted in public issues.

Deleting your data

  • In the game: Settings → Reset all progress resets game progress and preferences. It does not clear the offline cache or unsubscribe notifications; turn reminders off first.
  • In your browser: clearing site data removes local game data. Use notification settings to revoke permission, and turn reminders off in the game before clearing data to request send-list deletion. Clearing local data cannot itself delete the server record.

Advertising

Arrow Out! currently loads no advertising SDK, AdSense code, ad cookies or consent-management system. The rewarded-hint screen is a labelled five-second demo, not a real ad. No advertising provider is integrated. If a future release adds ads, its actual provider, data use and required user choices must be reviewed, implemented and disclosed before enabling that release. No consent or legal-compliance guarantee is made for a future integration.

Security

Your game progress stays on your device, which limits exposure, and the public GitHub Pages site and configured Supabase requests use HTTPS. Still, no online service can guarantee absolute security: information that travels over the internet (notification subscriptions, requests to GitHub Pages or Supabase) can in principle be intercepted or accessed by the parties operating those services. Please keep sensitive personal details out of public GitHub issues.

Privacy requests and limitations

This page describes the implemented behaviour; it is not a legal compliance certification. There is no automated access-request service or private contact form. For a general privacy question, use the Contact page without including personal data. Do not put push endpoints, encryption keys or other identifiers in public issues. This page does not provide a private route for sensitive requests or guarantee provider-side deletion.

Children

Arrow Out! has no accounts, and the game itself never asks for a name or email address; the Contact page asks only for a subject and message. Do not put personal details in them. Optional reminders still process device-linked identifiers and network metadata as described above. Any future advertising integration needs a separate review of age, consent and applicable privacy requirements before launch.

Changes

If this policy ever changes (for example, if advertising or a backup service is added), the updated policy will be published on this page with a new last-updated date.

Contact

General questions: use the Contact page or open an issue directly at github.com/parya5103/Fletch_Game/issues. Both routes lead to public issues; do not include private data.
