# Arrow Out! 🏹

A mobile-first **tap-away arrow puzzle** game — a single HTML file, zero dependencies, installable as a PWA. **1000 levels**: a short 50-level warm-up, then **EXTREME mode** — every level from 51 onward is a full 12×12 board packed with **100–130 arrows**. **3 free hints per level**, rewarded-ad hints after that.

Play online: `https://<your-user>.github.io/<repo>/` after enabling GitHub Pages (see below).

## How to play

- The board is a grid of arrows, each pointing up / right / down / left.
- Tap an arrow to launch it in the direction it points.
- An arrow can launch **only if nothing sits between it and the board edge** in its direction — if the ray is blocked, the tap is a mistake (1 of 3 hearts lost).
- Clear every arrow to win the level. Clear all **1000 levels** to complete the campaign 🏆
- **Undo** reverses your last launch, **Restart** resets the level.
- **Hints:** 3 free per level (a badge on the Hint button counts them down). After that, watch a short ad to reveal another hint.

## Difficulty ramp

| Levels | Board | Arrows |
|---|---|---|
| 1–50 | 5×5 → 8×8 warm-up | 5 → 42 |
| 51+ | **12×12 (EXTREME)** | **100 minimum → up to 130** |

From level 51 the gloves come off: every board is a full 12×12 grid with at least 100 arrows on it, climbing to 130 by level 1000. These boards are genuinely hard — plan multiple launches ahead.

## Every level is solvable — guaranteed

Levels are generated by **reverse placement**: arrows are placed one by one, and an arrow is only put on a square where its exit ray to the edge is clear at that moment. Reversing that build order always yields a valid clear order, so every level can be finished with zero mistakes, the Hint button can always point to a safe arrow, and deadlock states are impossible. For the extreme 100+ arrow boards the generator uses a **most-constrained-first** placement (the empty square with the fewest clear directions is filled first), which is what allows such dense boards to stay solvable. All 1000 levels are verified solvable with correct hints.

## Features

- 💯 **1000 levels** — 50 warm-ups then extreme 100–130-arrow 12×12 boards
- 💡 **3 free hints per level**, then a rewarded-ad hint (a clearly-labelled 5-second demo ad runs until a real ad provider is wired into `Ads.provider` — the rewarded flow is ready for AdSense/AdMob H5)
- 💾 **Auto-save** — stars, plays and current level save privately on your device; fully offline
- 📱 Mobile-first: touch pointer events, 44px+ action targets, safe-area aware, works from 320px-wide screens
- ⭐ 3-star scoring: ★★★ = no mistakes & no hints · ★★ = ≤2 mistakes & ≤1 hint · ★ = otherwise
- 🗺️ Level map with best stars, locked padlocks and current-level highlight
- 🔊 Synthesized sound effects via the Web Audio API — no audio files; mute toggle
- 📲 PWA: runtime manifest + canvas-generated icons, service worker, Android install prompt, iOS Add-to-Home-Screen hint
- 🎨 Dark neon theme, color-coded arrows, smooth overlay animations

## Ads

No ad code ships with the game. The architecture is ready:

- `Ads.showBanner()` unhides the banner slot under the board (`#ad-slot`).
- `Ads.requestRewarded(cb)` plays a provider's rewarded ad, or (until one is connected) a **clearly-labelled demo ad** so the hint-for-ad flow can be tested end to end.
- Wire a provider via `Ads.enabled = true; Ads.provider = { init, showBanner, requestRewarded }`.

## Run locally

Just open `index.html` in a browser, or serve the folder over HTTP so the service worker can register:

```bash
npx serve .
# or
python3 -m http server 8000
```

## Deploy on GitHub Pages

1. Push `index.html` and `sw.js` to your repository.
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/(root)` → Save.
3. Open `https://<your-user>.github.io/<repo>/` — install it from the in-game Install button (Android/Chrome) or Share → Add to Home Screen (iOS Safari).
